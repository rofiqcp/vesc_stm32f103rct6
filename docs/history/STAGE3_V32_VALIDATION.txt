STAGE3 v32 FULL RE-AUDIT VALIDATION
==================================

ROOT CAUSE FROM USER ARM BUILD LOG
---------------------------------
Stage3 v31 commands.c directly included FreeRTOS task.h without FreeRTOS.h first.
This corrupts FreeRTOS header parsing and causes the observed commands.c/list.h/stdio cascade.
Stage3 v32 removes direct task.h dependency and uses CMSIS-RTOS2 osThreadGetStackSpace().
