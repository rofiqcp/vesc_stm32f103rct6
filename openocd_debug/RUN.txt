VESC STM32F103RCT6 OPENOCD DEBUG - RUN

Copy folder "openocd_debug" into the firmware project root.
Expected ELF:
  .pio/build/stm32f103rc/firmware.elf

1) Build firmware:
   pio run -e stm32f103rc

2) Terminal A - start OpenOCD:
   ./openocd_debug/run_openocd.sh
   or:
   openocd -f openocd_debug/openocd.cfg

3) Terminal B - start GDB:
   ./openocd_debug/run_gdb.sh
   or:
   arm-none-eabi-gdb -x openocd_debug/gdb_debug.gdb

4) At GDB prompt, examples:
   boot_debug
   bp_threads_boot_once
   continue

   rtos

   monitor reset halt
   bp_isr_foc_once
   continue

   monitor reset halt
   bp_isr_sensor_once
   continue

   monitor reset halt
   bp_isr_comm_once
   continue

   faultstate
   irqstate
   motorregs

5) Non-intrusive stochastic profile:
   monitor vesc_profile_5s

IMPORTANT:
- Use ONE ISR breakpoint group at a time.
- DMA1_Channel1_IRQHandler is the ~16 kHz FOC current-loop ISR. Any breakpoint
  in this path changes real-time timing, so the script uses one-shot breakpoints.
- OpenOCD FreeRTOS awareness lets GDB 'info threads' see RTOS tasks when the ELF
  symbols and firmware on the MCU match.
